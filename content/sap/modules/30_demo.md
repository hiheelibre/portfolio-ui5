## 문제
통합테스트와 시연을 반복하려면 같은 조건의 데이터를 다시 만들고, 실행 결과를 안전하게 되돌릴 방법이 필요했습니다.

## 설계 내용
- 기존 데이터는 덮어쓰지 않고, 부족한 데이터만 추적 가능한 표시를 붙여 생성
- 기존 마스터는 건드리지 않음
- TEST 모드로 건수를 먼저 확인한 뒤 REAL 실행
- 해당 월 실행 데이터만 되돌리는 롤백 프로그램을 따로 준비

## 결과
시연 준비와 초기화를 반복할 수 있게 됨

## 내가 한 일과 팀이 한 일
설계와 개발 모두 직접

## 연결
- 받는 것: 결산 프로그램이 필요로 하는 선행 데이터 조건
- 넘기는 것: 시연용 데이터, 롤백
