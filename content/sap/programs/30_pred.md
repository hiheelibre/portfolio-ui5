## 개요
원자재를 수입하고 반제품을 직접 제조하는 가상 제조기업을 대상으로, 차기연도 표준원가 산정에 사용할 원자재 계획단가를 준비했습니다. 반제품 BOM을 전개해 필요한 원자재를 구성하고, 구매 계약단가의 연도별 추세와 담당자가 선택한 리스크 요인을 함께 반영했습니다. 산정 결과는 이력과 함께 검토하고 자재별 단가 방식을 결정할 수 있도록 구성했습니다.

### 이 프로그램이 다루는 범위
- 대상 원자재 구성
- 계약 이력 정제
- 예측 및 리스크 보정
- 담당자 검토
- 계획단가 버전 저장
- 후속 표준원가 산정의 입력값

## 업무 흐름
대상 원자재를 정하는 단계부터 표준원가 산정에서 저장 버전을 읽어 가는 단계까지 이어집니다.

| 순서 | 수행 내용 | 처리 기준 |
| --- | --- | --- |
| 1 | 대상 원자재 구성 | 반제품 BOM을 전개해 구성 원자재를 추출. 자재를 입력하지 않으면 전체 원자재를 조회 |
| 2 | 계약 이력 수집 | 구매정보레코드의 자재별 계약단가, 가격단위, 유효기간 |
| 3 | 분석 데이터 정제 | 목표연도 이상의 계약 제외, 연도별 최신 유효시작일 선택, 가격단위 환산, 같은 날짜 복수 건 평균, 최근 N개년 |
| 4 | 기준단가 산출 | ABAP 최소제곱법 선형회귀, 이력 부족 등 예외 분기 |
| 5 | 리스크와 계약상태 반영 | 공통으로 선택한 리스크와 자재별 적용 체크, 이전 예측 유지 또는 복사 |
| 6 | 담당자 검토와 단가 방식 선택 | 단가 이력 ALV와 차트를 보고 예측가 또는 직전 계약가 선택 |
| 7 | 저장 전 검증과 버전 저장 | 계획단가(ZTC1CO0027)와 리스크 적용 이력(ZTC1CO0043) 저장 |
| 8 | 표준원가 산정에서 활용 | 표준원가 프로그램(ZRC1CO0006)에서 저장 버전을 입력해 조회. 통합테스트 예시 버전은 299 |

### 주요 데이터 연결
| 데이터 | 테이블 | 역할 |
| --- | --- | --- |
| 원자재 | ZTC1MM0001 | 대상 자재 정보 |
| BOM | ZTC1PP0005 / ZTC1PP0006 | BOM 헤더와 상세. 반제품 BOM 전개에 사용 |
| 계약단가 | ZTC1MM0021 / ZTC1MM0022 | 구매정보레코드 헤더와 품목 |
| 리스크 기준 | ZTC1CO0041 | 리스크 요인과 가중치 |
| 계획단가 | ZTC1CO0027 | 자재, 연도, 버전 등을 키로 계획단가 저장 |
| 리스크 이력 | ZTC1CO0043 | SAVE_ID, FACTOR_ID 등으로 적용 리스크와 단가 방식 기록 |

표는 이 프로그램이 읽고 쓰는 데이터의 연결을 보여 주며, 각 테이블의 전체 키 정의는 아닙니다.

## 핵심 구현
### A. 회귀 입력 정제와 예외 처리
단가를 가격단위로 나누어 비교 기준을 맞추고, 연도별 최신 계약 시점을 대표값으로 선정했습니다. 같은 시점의 복수 레코드는 평균을 사용하고, 목표연도 이상의 계약은 회귀에 포함하지 않았습니다. 연도와 대표단가로 최소제곱법의 기울기와 절편을 계산합니다.

| 조건 | 처리 |
| --- | --- |
| 이력 없음 | 기준단가 0. 이후 유효단가 검증에서 저장 차단 |
| 사용 가능한 이력이 2개년 미만 | 최신 연도 단가 사용 |
| 회귀식 분모가 0 | 평균단가 사용 |
| 회귀 결과가 0 이하 | 최신 연도 단가로 보정 |

분석기간은 1~10년, 목표연도는 현재연도부터 현재연도+10년까지 입력하도록 검증합니다.

```abap
" 7. 선형회귀 계산
LOOP AT gt_contract_history INTO gs_contract_history.
  lv_x = gs_contract_history-gjahr.
  lv_y = gs_contract_history-netpr.
  lv_sum_x  += lv_x.
  lv_sum_y  += lv_y.
  lv_sum_xx += lv_x * lv_x.
  lv_sum_xy += lv_x * lv_y.
ENDLOOP.

lv_denominator = ( lv_n * lv_sum_xx ) - ( lv_sum_x * lv_sum_x ).
IF lv_denominator <> 0.
  lv_slope_a     = ( ( lv_n * lv_sum_xy ) - ( lv_sum_x * lv_sum_y ) ) / lv_denominator.
  lv_intercept_b = ( lv_sum_y - ( lv_slope_a * lv_sum_x ) ) / lv_n.
  pv_base_cost   = ( lv_slope_a * lv_target_x ) + lv_intercept_b.
ELSE.
  pv_base_cost = lv_sum_y / lv_n.
ENDIF.
```

### B. 리스크 선택과 계산
예측단가 = 기준단가 × (1 + 해당 자재에 적용한 리스크 가중치 합)

팝업에서 공통 후보 리스크를 선택한 뒤, 자재별 체크로 적용 여부를 정합니다. 공통 선택과 자재 체크를 모두 만족하는 요인만 합산합니다.

- 선택은 최대 10개
- 가중치(weight) 오름차순, 같으면 factor_id 순으로 APPL_1~APPL_10 슬롯에 대응
- 계산, 표시, 저장에 같은 대응 규칙을 쓰고, 저장된 이력은 factor_id 기준으로 복원
- 가중치는 담당자가 리스크 기준에 설정한 값을 사용

### C. 계약상태와 단가 방식
| 구분 | 내용 |
| --- | --- |
| 재산정 대상 | 예측가(P) 또는 직전 계약가(C)를 자재별로 선택하거나 일괄 적용 |
| 유지 대상 | 계약이 유효하고 목표연도에 저장된 예측이 있음. 이전 예측단가 유지(K), 저장 대상에서 제외 |
| 복사 대상 | 계약이 유효하고 목표연도 예측은 없으나 이전연도 예측이 있음. 이전 예측단가 사용(K), 저장 대상 |
| 확인 필요 상태 | 계약이 없거나 유지에 필요한 예측 데이터가 없는 경우 등 |

유지, 복사 대상은 리스크와 단가 방식 편집을 제한하고, 변경 이벤트에서도 허용되지 않은 편집을 되돌리는 방식으로 상태를 관리했습니다. K는 계약단가 자체가 아니라 이전 예측단가를 그대로 쓰는 방식입니다.

### D. 저장과 후속 연계
편집값을 확정한 뒤 저장 가능한 데이터인지 검사하고, 버전 입력과 신규, 갱신 건수 확인을 거쳐 저장합니다. 단가가 0 이하인 무효 데이터는 저장을 막습니다.

최종 저장은 키 기준 MODIFY로 신규와 갱신을 함께 처리하며, 최초 생성 정보와 변경 정보를 구분해 남깁니다. 계획단가와 적용 리스크 이력을 함께 기록하고, 오류가 나면 전체를 롤백하는 경로를 두었습니다.

계획단가는 200번대 버전으로 저장하고, 표준원가 프로그램에서는 저장한 버전을 입력해 읽습니다. 통합테스트에서는 299 버전을 예시로 사용했습니다.

## 문제 해결
개발 중 다룬 문제 가운데 세 가지를 정리했습니다.

### 1. 같은 연도에 여러 계약이 있고 가격단위가 다른 데이터
- 처리: 단위단가 환산, 연도별 대표 계약 선정, 목표연도 이상 계약 제외, 이력 부족과 0 이하 결과의 예외 분기
- 확인: 아래 검증 및 기여의 계산 예시에서 수식과 입력 기준을 확인할 수 있습니다

### 2. 선택한 리스크 개수와 고정 ALV 구조의 차이
- 처리: 고정 10개 슬롯을 두고 ASSIGN COMPONENT로 슬롯에 접근, 선택한 리스크 컬럼만 표시, factor_id 기준으로 이력 복원
- 확인: 자재별 리스크 적용과 저장 이력 복원이 같은 대응 규칙을 사용합니다

### 3. 변경한 값과 저장 상태 표시의 불일치
- 처리: 값이 실제로 바뀐 경우에만 상태 갱신, 저장값과 비교할 때 소수점 기준 통일, 저장 상태 컬럼 강조색이 개별 셀 색을 덮지 않도록 컬럼 강조색 제거
- 확인: 편집 상태와 저장 상태를 같은 비교 기준으로 표시합니다

## 검증 및 기여
### 계산 예시: RMBAT110 / 목표연도 2026 / 분석기간 3년
| 연도 | 단가 | 회귀 반영 |
| --- | --- | --- |
| 2023 | 4,100 | 사용. 최신 유효시작일 계약 기준이며 같은 해 이전 계약 3,780은 제외 |
| 2024 | 4,250 | 사용 |
| 2025 | 4,460 | 사용 |
| 2026 | 4,680 | 목표연도에 해당하므로 제외 |

세 해의 단가로 계산한 기울기는 180, 절편은 -360,050이며, 2026년 회귀 기준단가는 4,630입니다.

리스크 가중치 합 5%를 적용하면 4,630 × 1.05 = 4,861.5가 계산상 기대값입니다. 수식으로 계산한 예시이며, 실제 화면이나 저장 결과로 확인한 값은 아닙니다.

### 통합테스트 시나리오
- 리스크 선택과 변경
- 자재별 단가 이력 검토
- 일부 자재는 직전 계약가 선택
- 299 버전으로 저장
- 후속 표준원가 산정에서 해당 버전 사용

### 기여
> CO 담당자로 원자재 계획단가 산정 기능을 설계하고 ABAP으로 구현했습니다. 계약 이력의 정제, 예측 및 리스크 반영, 단가 검토, 저장 상태와 버전 관리를 연결했습니다. 팀에서 제공한 구매정보레코드와 BOM을 활용하고, 후속 표준원가 산정에서 사용할 버전 규칙을 연계했습니다.

### 배운 점
> 예측식을 구현하는 것만큼 입력 데이터의 기준과 예외 처리가 중요했습니다. 산정값과 함께 계약 이력과 적용 리스크를 확인할 수 있게 하고, 값의 변경과 저장 상태를 함께 관리하는 데 집중했습니다.

프로젝트 대상(28개 팀 중 1위)은 7인 팀 전체의 성과입니다.
